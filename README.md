# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница с популярными товарами и формой заявки;
- `catalog.html` — каталог с боковым блоком фильтров и сеткой товаров;
- `contacts.html` — контактная информация и ссылка на форму обратной связи;
- `css/style.css` — файл стилей;
- `js/main.js` — открытие и закрытие модального окна, управление фокусом и обработка формы;
- `images/preview.jpg` — изображение для Open Graph (1200 × 630 px);
- `sitemap.xml` — карта сайта для GitHub Pages;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Текущий статус

Сайт состоит из трёх страниц: главной, каталога и контактов. На всех страницах используются общие шапка, меню и подвал. Добавлены якорные ссылки, хлебные крошки, уникальные заголовки и описания страниц. Каталог организован через именованные области CSS Grid: фильтры слева, товары справа. Меню и содержимое карточек выровнены через Flexbox, отступы заданы через `gap`. Сохранены модальное окно оформления заявки и базовая валидация формы.

## Реализованные элементы интерфейса

- горизонтальная навигация на Flexbox с выравниванием пунктов, равным `gap`, увеличенной областью ссылок и подсветкой при наведении;
- двухколоночный каталог на CSS Grid с областями `filters` и `products`;
- форма-макет фильтров с категориями и диапазоном цен;
- адаптивная сетка карточек товаров на CSS Grid: три колонки на широких экранах, две при ширине до 800 px и одна при ширине до 540 px;
- выравнивание кнопок по нижнему краю карточек через Flexbox;
- закреплённая при прокрутке шапка через `position: sticky` и отступы для переходов по якорным ссылкам;
- кнопки заказа в карточках товаров;
- подсветка кнопок при наведении и видимый фокус при клавиатурной навигации;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- светлый фон всех полей при открытии окна; при выборе одного поля остальные затемняются, выбранное остаётся светлым;
- возврат светлого фона при уходе фокуса из полей, в том числе при клике по свободному месту модального окна;
- отсутствие подсветки полей при наведении мыши;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной проверке заявки; данные не отправляются на сервер, так как backend не подключён.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus`, `:focus-visible`, `:disabled`;
- селектор `:has()` для затемнения остальных полей при выборе одного из них;
- Flexbox для шапки, навигации, содержимого карточек и кнопок формы;
- CSS Grid для сетки товаров и медиазапросы для адаптивной раскладки;
- `position: sticky`, `top` и `z-index` для позиционирования шапки;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- стили хлебных крошек, активной страницы через `aria-current` и цели якоря через `:target`;
- плавная прокрутка с учётом настройки `prefers-reduced-motion`;
- общий файл `css/style.css`.


## Навигация

На каждой странице меню содержит ссылки «Главная», «Каталог», «Контакты»,
«Преимущества», «Популярные товары» и «Обратная связь».
Текущая страница выделена и помечена `aria-current="page"`.
На внутренних страницах есть хлебные крошки: «Главная / Каталог»
и «Главная / Контакты». Текущий пункт оформлен через `span`.

Якоря главной страницы:

- `#advantages` — преимущества проекта;
- `#popular` — популярные товары;
- `#contacts` — обратная связь с кнопкой «Оставить заявку».

Ссылки вида `index.html#popular` работают с любой страницы сайта.
Кнопки «Заказать» передают название выбранного товара в модальную форму.
Кнопка «Оставить заявку» открывает ту же форму для общего обращения.

## Дополнительные элементы

- `sitemap.xml` содержит абсолютные адреса всех трёх страниц GitHub Pages.
- Каждая страница содержит Open Graph-теги с собственными заголовком,
  описанием и URL, а также общим изображением `images/preview.jpg`.
- Контактные данные на странице контактов являются демонстрационными.

## Запуск и проверка

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`.

1. Перейдите с главной страницы в каталог и контакты, затем обратно.
2. Проверьте одинаковые пункты меню и выделение текущей страницы.
3. На внутренних страницах нажмите «Главная» в хлебных крошках.
4. С каждой страницы перейдите к преимуществам, популярным товарам и обратной связи.
5. Убедитесь, что нужный раздел виден и выделен пунктирной рамкой.
6. В каталоге нажмите «Посмотреть на главной», в контактах — «Перейти к форме».
7. Проверьте открытие формы кнопками «Заказать» и «Оставить заявку»,
   закрытие кнопкой и Escape, ошибки пустой формы и успешную проверку заполненной.
8. Проверьте уникальные `title`, `meta description`, Open Graph и подключение CSS
   в исходном коде каждой страницы.
9. Откройте `sitemap.xml` и `images/preview.jpg`.

## Использование Flexbox и Grid

- `.site-header` и `.site-nav__list` используют Flexbox. Свойства
  `justify-content`, `align-items`, `flex-wrap` и `gap` выравнивают меню
  и задают одинаковые промежутки между пунктами.
- `.product-card` использует `display: flex`, `flex-direction: column`
  и `gap: var(--space-sm)`. Кнопки прижаты к нижнему краю карточек
  через `margin-top: auto` и `align-self: flex-start`.
- `.products-grid` на главной странице и в каталоге использует CSS Grid
  с тремя равными колонками и `gap: var(--space-lg)` на широком экране.
- `.catalog-layout` использует колонки `260px minmax(0, 1fr)` и
  `grid-template-areas: "filters products"`. Блоки `.catalog-filters`
  и `.catalog-products` занимают одноимённые области через `grid-area`.
- `.filters-form` использует Grid и `gap` между группами полей.
  Категории и цены сгруппированы через `fieldset` и `legend`.

Фильтры в практике №6 являются макетом интерфейса: поля можно заполнять,
но список товаров пока не фильтруется, кнопка «Применить» отключена.
Обработка фильтров не входит в задание на раскладку.
Ранее добавленные медиазапросы сохранены; новые правила адаптивности
в рамках практики №6 не добавлялись.
