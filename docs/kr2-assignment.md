# Постановка контрольной работы №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Цель — разработать интерфейс магазина с использованием компонентов и сетки
CSS-фреймворка. КР №2 выполняется в отдельном репозитории `kr2-bootstrap-shop`.
Это новая реализация той же предметной области, а не подключение Bootstrap
к готовому HTML/CSS-проекту КР №1. Практика №8 содержит постановку следующей
работы; готовый проект КР №1 остаётся в `kr1-html-css-shop`.

## Предметная область

Магазин товаров для рабочего места: лампа, органайзер и подставка для ноутбука.
Сохраняются каталог, карточки товаров, характеристики, цены, форма заявки,
навигация, модальное окно и единый стиль.

## Обязательная структура

```text
kr2-bootstrap-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── css/
│   └── custom.css
└── README.md
```

| Страница | Содержание |
| --- | --- |
| `index.html` | Bootstrap-навигация, hero-блок и карточки |
| `catalog.html` | Каталог с сеткой Bootstrap |
| `product.html` | Изображение, характеристики, цена и badge |
| `order.html` | Форма заявки с Bootstrap-элементами |

`contacts.html` можно добавить дополнительно.

## Компоненты Bootstrap

- Сетка: `container`, `row`, `col-*`.
- Навигация: `navbar`.
- Карточки: `card`.
- Кнопки: `btn` и варианты.
- Формы: `form-control`, `input-group`, `form-check`.
- Модальное окно: `modal`.
- Сообщения: `alert`.
- Значки: `badge`.
- Дополнительный компонент по выбору: `accordion`, tabs или `carousel`.

Основной вариант — Bootstrap. Tailwind CSS или Bulma допускаются по согласованию
с преподавателем при сохранении требований к сетке, карточкам, формам, модальному
окну и навигации. Подключение Bootstrap через CDN или локально выбирается
с учётом указаний преподавателя. Собственные дополнения размещаются в `css/custom.css`.
